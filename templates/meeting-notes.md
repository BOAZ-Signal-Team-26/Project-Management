# 회의록 Template

**이 페이지를 Notion의 회의록 DB에 생성할 때 복사해서 사용하세요.**

---

## 작성 규칙

> 회의록을 쓰기 전에 **직전 회의 회의록을 먼저 읽고**, 그 내용을 참고해서 작성합니다.

- 직전 회의록에서 **결론, 의사결정, 액션 아이템, 추후 논의 필요 사항**을 확인하고 이번 회의록에 이어지도록 씁니다.
- 직전 회의의 액션 아이템은 아래 「이전 회의 액션 아이템 점검」 표에 그대로 옮겨 적고, 이번 회의에서 결과를 채웁니다.
- 직전 회의에서 넘어온 미결은 「추후 논의 필요 사항」에 남겨 두고, 이번 회의에서 어떻게 처리할지를 함께 적습니다.
- 직전 회의록에 링크를 겁니다. 「첨부 자료 → 관련 Ticket / Notion 페이지」에 기재합니다.

## 논의 사항

### 안건 1: 지난 작업·조사 내용 공유 (고정)

**공유 범위 규칙:**

- 스프린트 주기가 **2주**이면, 공유 범위는 스프린트 전체가 아니라 **직전 1주**에 진행한 작업으로 한정합니다.
- 티켓 기간이 **2주**이면 완료 보고가 아니라 **진행 상황 공유**로 처리하고, 이번 회의에서는 완료 판정을 하지 않습니다.
- 마감일이 이번 회의 당일이거나 그 이전인 티켓만 **완료 여부를 판정**합니다.

**공유 범위:** [YYYY-MM-DD] ~ [YYYY-MM-DD] (스프린트 [Week N], 주기 [1주 / 2주])

#### 티켓 진행 공유

| 티켓 | 담당 | 마감 | 티켓 기간 | 이번 회의 처리 | 공유 내용 |
|---|---|---|---|---|---|
| [티켓명] | [이름] | [YYYY-MM-DD] | [1주 / 2주] | [완료 판정 / 진행 상황 공유] | [내용] |
| | | | | | |

> 진행 상황은 세 줄로 씁니다. **끝난 것 / 남은 것 / 마감일까지 완주 가능한가 (O·X)**

#### 조사·스터디 공유

> 티켓에 속하지 않은 조사·학습 내용을 인당 1건씩 공유합니다.

| 이름 | 조사·학습 내용 | 팀 작업에 미치는 영향 |
|---|---|---|
| [이름] | [내용] | [영향] |
| | | |
