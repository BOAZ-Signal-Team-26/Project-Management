## 1. EPIC 로드맵 DB

용도: 큰 주제/목표 관리

### 속성

| 속성명 | 타입 | 설명 |
|---|---|---|
| 프로젝트 (제목) | 텍스트 | Epic 이름 |
| 진행 상태 | 상태 | 진행 단계 |
| 우선순위 | 선택 | 중요도 |
| 기간 | 날짜 | 시작–종료 |
| 담당자 | 사람 | 담당 팀원 |
| 임팩트 | 숫자 (1–10 막대) | 예상 영향도 |
| 리소스 | 숫자 (1–10 막대) | 필요 리소스 |
| 리소스/임팩트 지표 | 텍스트 | 효율성 메모 |
| 비고 | 텍스트 | 추가 정보 |
| Figma | 텍스트 | Figma 링크 |
| 상시 Sprint | 선택 | 진행 중인 스프린트 태그 |
| 선행 작업·후속 작업 | 관계 (자기 참조) | 의존성 |
| 엔지니어링 작업 | 관계 (Ticket DB) | 연결된 Ticket |
| 디자인 Ticket | 관계 | 연결된 디자인 작업 |
| 개발 문서·디자인 문서 | 관계 | 참고 문서 |
| 리서치 프로젝트·테스트 | 관계 | 관련 리서치/테스트 |
| 테스트·리서치·Study 문서 | 관계 | 참고 자료 |

### 선택지

**진행 상태**
- 해야 할 일
- 진행 중
- 디자인 중
- 개발 중
- CI/CD 준비
- 중단
- 개발 완료
- 진행 완료
- 취소

**우선순위**
- 낮음
- 중간
- 높음
- 매우 높음

### 기본 템플릿

- `프로덕트 스펙`

### 뷰

- 보드 (기본)
- 진행 중
- 백로그 우선순위별
- 타임라인
- 목표 론칭일
- 준비 완료된 작업
- 전체 보기

## DB 간 관계도

```
EPIC 로드맵 DB
    ├─ (포함) 엔지니어링 (Ticket) 작업 DB
    ├─ (포함) 디자인 (Ticket) 작업 DB
    └─ (참고) 엔지니어링 문서 / 테스트·리서치·Study 문서

Sprint 관리 DB
    ├─ (포함) 엔지니어링 (Ticket) 작업 DB
    ├─ (포함) 디자인 (Ticket) 작업 DB
    └─ (연결) 엔지니어링 회의 (Sprint 회의) DB

엔지니어링 (Ticket) 작업 DB
    ├─ Epic로 연결 → EPIC 로드맵 DB
    ├─ Sprint로 연결 → Sprint 관리 DB
    └─ (참고) 엔지니어링 문서 / 테스트·리서치·분석 문서

엔지니어링 회의 (Sprint 회의) DB
    └─ 팀 스프린트으로 연결 → Sprint 관리 DB

회의록 DB
    └─ (독립적)
```
