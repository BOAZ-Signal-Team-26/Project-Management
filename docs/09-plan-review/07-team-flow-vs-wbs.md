# 팀장 작업 흐름 초안과 WBS 대조

**작성:** 2026-09-09 · **검토 주체:** 데이터 엔지니어 / 데이터 사이언티스트 / 클라우드 아키텍트 / PM 역할 에이전트 4인 (문서 기반, 읽기 전용)
**검토 대상:** 팀장이 2026-09-09에 제시한 「Data 엔지니어링 / DA & DS」 작업 흐름 초안 ↔ [06-wbs.md](../06-wbs.md), [05-timeline.md](../05-timeline.md), [06-goal-backward-review.md](06-goal-backward-review.md)
**질문:** 초안의 흐름대로 WBS가 구성되어 있는가. 아니라면 어디가 다르고, 그 차이에 결정 기록이 있는가.

표기 규칙: [README.md](../../README.md) 참조. **(사실)**은 문서에서 직접 확인한 것, **(판단)**은 검토자의 추론이다.

## 0. 결론

**데이터 엔지니어링 4개 층은 WBS에 그대로 있다. 그러나 DA & DS 5단계는 WBS와 다른 프로젝트를 그리고 있다 (판단, 4인 일치).**

초안은 「라벨 확보 → 지도학습 모델 → MLflow·SageMaker 배포 → Product」를 전제한다. WBS는 「규칙 기반 CDI 4축 점수 → 위험등급·상품유형 통제 잔차 → 약라벨로 H1 검정 → 대시보드 3화면 + 개선안 문서」다. 같은 문제의식(설명이 어려운 상품을 찾는다)을 다루지만 기술적 해법이 다르다.

초안의 전제 가운데 2건은 Week 2 실측으로 이미 무효화되었다 **(사실)**. 「파싱이 가장 고생하는 구간」은 DART가 정형 HTML로 확인되어 무효이고(05-timeline.md:32), 「분쟁 결정문에서 골든 데이터셋」은 당사자·상품명 전량 마스킹과 조인 키 부재로 무효다(05-timeline.md:34). 두 번째 무효화로 LLM augmentation의 전제(원본-라벨 쌍)도 함께 사라졌다.

**결정 기록 없이 사라진 범위가 4건 있다 (사실).** user study, LLM augmentation, 지도학습 Modeling, MLflow·SageMaker 배포는 docs 전체에 단어 자체가 0건이다 (2026-09-09 grep 확인). 초안이 08-26 이전 인식이라 해도, 빠진 이유를 어디에도 남기지 않았으므로 팀원은 여전히 그 단계를 기다릴 수 있다.

## 5. 사라진 범위의 결정 기록 여부 **(사실)**

| 초안 항목 | 기록 | 처리 방향 (제안) |
|---|---|---|
| user study | 없음 | 금소법 19조 점검표로 대체했다는 결정을 06-wbs 0절에 1줄 기록 |
| LLM data augmentation | 없음 | 결정문 마스킹으로 전제 상실. Week 2 실측 정정 5건 표에 "augmentation 근거 상실" 1줄 추가 |
| 지도학습 Modeling | 없음 | Phase 1 산출물은 예측 모델이 아니라 CDI 점수임을 명시. 모델은 Phase 2 이월 |
| MLflow·SageMaker 배포 | 부분 (D5는 이력 기록만) | D5를 실험 추적 용도로 한정한다고 명시. 서빙은 Phase 2 이월 |
| Feature Engineering·가중치 | 부분 (가중치 산정 방식 미정) | 그대로 유지 |
| Product화 | 대체됨 (발표 없음, 대시보드 3화면) | 05-timeline.md:17 |

## 6. 오늘(5차 미팅) 결정할 3건 **제안**

1. **Phase 1 산출물은 예측 모델이 아니라 CDI 점수·대시보드·개선안이다**라고 명시하고, 지도학습 Modeling과 MLflow·SageMaker 배포는 Phase 2 이월로 결정 기록을 남긴다.
2. **불완전 판매 기준은 금소법 19조 점검표(09-16 마감)로 확정**하고 user study는 범위에서 뺀다. user study를 넣으려면 09-16 마감과 M1 통과 조건이 함께 밀린다.
3. **역할은 WBS 기준으로 확정**한다. 민석=도메인·검정·앱 실측, 주영=수집·저장소·파이프라인·대시보드 배포, 다빈=지표·잔차·민감도. 초안의 "민석 DE / 다빈 Modeling / 주영 배포" 문구는 폐기한다.

이 밖에 09-16 관문 A 전에 닫을 것: 품질 층을 Phase 1에 두는 현행 유지 확인(초안과 반대), SCD Type 2 컷 여부 10-28 결정 유지, 초안의 6필드 목록(상품유형·판매사·위험등급·수수료 체계·원금손실 고지 위치·핵심 위험 문구)을 관문 C의 입력으로 그대로 채택할지.

## 7. 기존 검토와의 관계

[06-goal-backward-review.md](06-goal-backward-review.md)는 최종 목표 문구에서 WBS로 내려오는 사슬을 봤고, 이 문서는 팀장의 작업 흐름 초안에서 WBS로 올라가는 사슬을 봤다. 두 방향 모두에서 WBS의 DE 부분은 온전하고, 차이는 「무엇을 산출하는가」(모델 vs 지표)에 집중된다.
